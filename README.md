# Адиль Сарсембек — Системный аналитик

Адаптивный сайт-резюме на русском, казахском и английском языках: опыт, навыки, образование, обучение и контакты. Поддерживает светлую и тёмную темы, настройку анимации, поиск курсов, скачивание PDF и контактной карточки.

- Сайт: https://adil10961.github.io/adil-sarsembek-analyst/
- Репозиторий: https://github.com/adil10961/adil-sarsembek-analyst

## Публикация

Сайт работает как набор статических файлов, без сервера и установки зависимостей. GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Пути к ресурсам относительные и работают в подкаталоге проекта.

## Редактирование

- `content.json` — тексты на трёх языках.
- `assets/render.js` — шаблон страницы и подписи интерфейса.
- `assets/style.css` — оформление и адаптивность.
- `assets/app.js` — переключатели и взаимодействия.
- `assets/adil-sarsembek-system-analyst.pdf` — PDF-резюме; заменяется отдельно.
- `assets/adil-sarsembek.vcf` — контактная карточка.

После изменения текстов или шаблона выполните из папки проекта:

```sh
node build.cjs
```

Команда обновляет `index.html`, `assets/data.js`, иконку и `.nojekyll`. Готовые файлы включены в репозиторий, поэтому для просмотра сборка не требуется. После изменений сохраните и отправьте файлы в ветку `main`: GitHub Pages обновит сайт.

При смене адреса сайта измените `origin` в `build.cjs` и выполните сборку: адрес используется в canonical, Open Graph и структурированных данных.
